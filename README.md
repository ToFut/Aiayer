# Memory System

A comprehensive memory management system for AI applications, providing short-term, long-term, and contextual memory capabilities.

## Features

- Short-term memory management
- Long-term memory storage
- Contextual memory tracking
- Memory visualization dashboard
- Real-time memory metrics
- Memory system health monitoring

## Installation

```bash
pip install -e .
```

## Usage

```python
from memory.memory_system import MemorySystem

# Initialize the memory system
memory_system = MemorySystem()

# Start the memory system
await memory_system.initialize()
```
