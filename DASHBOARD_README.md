# Task Memory Dashboard

The Task Memory Dashboard provides a visual interface to monitor, analyze and manage task memory metrics across your system. It offers comprehensive visualizations and controls for tracking task execution, memory usage, and value metrics.

## Features

- **Real-time Task Monitoring**: View active, completed, and failed tasks with detailed progress tracking
- **Performance Metrics**: Track execution times, success rates, and system performance
- **Memory Usage Analysis**: Monitor memory consumption and growth over time
- **Value Metrics**: Visualize time saved and monetary value generated by automated tasks
- **Comprehensive Reports**: Generate detailed reports with ROI calculations and efficiency metrics
- **Interactive Controls**: Search, filter, and view detailed task information

## Getting Started

### Starting the Dashboard

1. Run the dashboard server using the provided script:

```bash
./start_dashboard.sh
```

2. Access the dashboard in your web browser at:

```
http://localhost:8081
```

### Stopping the Dashboard

To stop the dashboard server:

```bash
./stop_dashboard.sh
```

## Dashboard Sections

### Overview
Provides a high-level view of system status including:
- Task counts (total, active, completed, failed)
- Success rates and completion times
- Active tasks chart
- System health metrics

### Tasks
Displays a searchable, filterable list of all tasks with:
- Detailed task information
- Progress tracking
- Execution history
- Context information

### Performance
Tracks system performance metrics including:
- Average operation times
- Operation counts
- Performance trends over time

### Memory Usage
Monitors memory utilization:
- Total memory size
- Average task size
- History entries count
- Growth trends

### Value Metrics
Calculates business value:
- Total time saved
- Monetary value generated
- ROI calculations
- Value trends over time

### Reports
Provides access to comprehensive reports:
- Historical reports with detailed metrics
- ROI analysis
- Time-based statistics

## Integration

The Task Memory Dashboard integrates with:

- **Task Memory Manager**: For persistent task state and history
- **Task Context Awareness**: For enriched contextual information
- **Universal Task Loop Controller**: For task execution data

## Technical Details

- Built with Flask for the backend API
- Uses Bootstrap for responsive UI
- Visualizations powered by Chart.js
- Real-time data updates with periodic polling
- Persistent storage of metrics and reports

## Customization

To customize dashboard settings, modify the following files:

- `memory/dashboard_server.py`: Update API endpoints and server configuration
- `memory/task_memory_dashboard.py`: Adjust metrics calculation and reporting intervals
- `web/dashboard/static/css/dashboard.css`: Customize dashboard appearance
- `web/dashboard/static/js/dashboard.js`: Modify client-side functionality

## Troubleshooting

- If the dashboard fails to start, check the log file at `logs/dashboard_startup.log`
- For API errors, check `logs/memory/dashboard_server.log`
- For metrics collection issues, check `logs/memory/task_dashboard.log`
