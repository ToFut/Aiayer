API Reference

The Neural UI Detector server accepts the following actions:

  • detect - Detects all UI elements on the screen
  • find - Finds a specific UI element (requires description parameter)
  • click - Clicks on a specific UI element (requires description parameter)
  • type - Types text into an input field (requires description and text parameters)
  • key - Presses a specific keyboard key (requires key parameter)
  • hotkey - Presses a key combination (requires keys array parameter)
  • execute - Executes a sequence of actions (requires steps array parameter)

Example message format:

{
  "action": "detect"
}

or

{
  "action": "find",
  "description": "submit button",
  "element_type": "button"
}
