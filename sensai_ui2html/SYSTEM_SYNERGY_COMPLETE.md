## 🎯 Usage Examples

### 1. **Real-time UI Context**
```json
{
  "type": "get_current_ui",
  "payload": {}
}
```
**Response**: Current app (Finder) with 333 elements

### 2. **Semantic Memory Queries**
```json
{
  "type": "ui_memory_query", 
  "payload": {
    "query": "Finder",
    "limit": 3
  }
}
```
**Response**: 3 relevant UI snapshots from memory

### 3. **Contextual Chat**
```json
{
  "type": "user_interaction",
  "payload": {
    "query": "What's on my screen?",
    "mode": "chat"
  }
}
```
**Response**: Contextual response with current UI state

### 4. **Agent Execution**
```json
{
  "type": "agent_execute",

    "action": "Click the first button"
  }
}
```
**Response**: Action execution result
